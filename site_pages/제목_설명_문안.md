# 블로그 제목·설명 문안 (4단계)

경로: 티스토리 **블로그 관리 → 블로그 → 블로그 이름 / 설명**

## 제목 (권장)

```
여행365 - 직접 다녀온 김포 맛집과 해외 여행 기록
```

**왜 이것인가**
- `여행365` 유지 → 도메인 `travelkorea365.live`·네이버/인스타 브랜드와 이어짐
- `직접 다녀온` → E-E-A-T 신호이자 **사실** (19편 전부 실사진·실경험)
- `김포 맛집 + 해외 여행` → 실제 콘텐츠 구성 그대로(김포 맛집 11 / 해외여행 8)
- **없는 걸 약속하지 않음** ← 기존 제목 "오늘 어디 갈까, 여행365"의 문제는 국내여행 글이 0편인데 국내여행 사이트로 읽힌다는 것

> ⚠️ **하이픈은 반드시 일반 `-`(ASCII)로.** 처음 이 문안에 en dash(`–`)를 썼다가, 붙여넣기 과정에서 리터럴 `&ndash;` 문자열로 저장되는 사고가 났습니다(2026-08-01). 결과: `<title>`은 우연히 정상 렌더되지만 `og:title`이 `&amp;ndash;`로 이스케이프돼 **SNS 공유·검색결과에서 `여행365 &ndash; 직접…`으로 깨져 보임.** 특수 대시·따옴표는 쓰지 마세요.

**대안** (김포 비중을 더 앞세우고 싶으면)
```
여행365 – 김포 동네 맛집, 직접 먹어보고 씁니다
```
→ 해외여행 8편이 제목에서 빠지는 게 유일한 단점.

## ⚠️ 현재 설정된 설명 (실측 — 이게 지금 검색결과·크롤러에 노출됨)

```
국내 곳곳의 여행지를 계절·테마별로 큐레이션하는 공간입니다. 명소, 코스,  가족 여행,
맛집 정보를 직접 검증해 매일 업데이트합니다. 주말마다 어디 갈지 고민이라면.
전국 여행지를 계절별로 정리해 떠나기 좋은 곳을 매일 추천합니다.
가족 나들이·꽃놀이·휴양 코스까지.
```

**문제 4개**
1. `국내 곳곳의 여행지` `전국 여행지` — 국내여행 글 **0편**
2. `계절·테마별` `가족 여행` `꽃놀이·휴양 코스` — 전부 **0편**
3. `매일 업데이트` — 사실 아님 (과장)
4. 뒤 두 문장이 앞 문장을 다시 말하며 같은 키워드를 반복 → **키워드 스터핑 성격**

이 description은 사이트의 자기소개로 가장 먼저 읽히는 문장입니다. **빈 카테고리를 지운 효과를 이 한 칸이 그대로 되돌리고 있습니다.** 4단계에서 이게 제일 중요합니다.

## 설명 (권장 — 위 문장을 통째로 교체)

```
김포에서 직접 먹어보고 쓴 동네 맛집 기록과, 다녀온 해외 여행·골프 후기.
사진은 전부 직접 촬영했고 가격은 방문 당시 매장 메뉴판 기준입니다.
```

한 줄만 들어가는 칸이면:
```
직접 가서 먹어보고 다녀온 곳만 씁니다 — 김포 동네 맛집과 해외 여행 기록
```

## ⛔ 쓰지 말 것

- **"365일 매일 새롭게"** — 발행 빈도가 그렇지 않고, 과장은 감점 요소
- **"국내여행지 소개"** — 국내여행 글 0편. 기존 소개 페이지의 가장 큰 문제
- **계절별 추천 / 가족여행 / 레시피 / 가전 리뷰 / 생활꿀팁** — 전부 콘텐츠 0
- **제휴 마케팅 고지** — 이 블로그에 제휴 링크가 **한 건도 없음**(전수 확인). 없는 걸 선언하면 오히려 상업 목적 사이트로 읽힘

## 같이 교체할 것

`site_pages/블로그_소개.html` → 티스토리 `/pages/블로그-소개` 페이지 본문 전체 교체.
기존 소개 페이지가 국내여행·계절별·가족여행을 약속하고 있어 **빈 카테고리를 지운 효과를 문장으로 되돌리고 있음.**
