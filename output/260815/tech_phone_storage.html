폰 저장공간 부족할 때 해결법 — 카톡 캐시·사진 중복 삭제 순서

"저장공간이 부족합니다"라는 알림이 뜨는 순간, 새 사진도 못 찍고 앱 업데이트도 안 되는 불편이 시작됩니다. 128GB 폰을 써도 어느새 꽉 차 버리는 이유는 카카오톡 캐시·사진 중복 저장·앱 데이터가 눈에 띄지 않게 쌓이기 때문입니다. 돈 안 들이고 5~20GB를 확보할 수 있는 순서와 방법을 안드로이드·아이폰 양쪽 기준으로 정리했습니다.

01 | 공간 얼마나 남았는지 먼저 파악하기

해결책을 쓰기 전에 현재 저장 상태를 먼저 확인해야 어디를 비울지 알 수 있습니다.

안드로이드: 설정 → 배터리 및 디바이스 케어(또는 저장공간) → 저장공간 탭에서 사진·동영상·앱·시스템·기타 항목별 용량 확인

아이폰(iOS): 설정 → 일반 → iPhone 저장 공간 → 각 앱별 사용 용량 리스트 확인. 상단 '권장 사항'에 iOS가 자동 제안하는 정리 방법이 표시됩니다.

공간을 가장 많이 차지하는 카테고리가 무엇인지 확인한 후, 그 순서대로 아래 방법을 적용하세요.

02 | 카카오톡 캐시 삭제 — 가장 먼저

카카오톡은 대화 중 공유된 사진·동영상·GIF·파일을 기기에 자동 캐시(임시 저장)합니다. 오랫동안 쌓이면 1~5GB를 차지하는 경우가 흔합니다.

카카오톡 캐시 삭제 방법
카카오톡 앱 → 하단 우측 더보기(≡) 탭 → 설정(톱니바퀴) → 개인정보 보호 → 캐시 데이터 삭제
또는: 설정 → 채팅 → 대화 저장 공간 관리 → 캐시 삭제
주의: 캐시 삭제는 대화 내용·연락처를 지우지 않습니다. 다만 대화방에서 공유했던 사진·파일의 미리 보기가 삭제되어 재다운로드가 필요합니다. 꼭 필요한 파일은 미리 기기 갤러리나 클라우드에 저장한 뒤 삭제하세요.

파일 저장 폴더도 확인하세요. 카카오톡 → 더보기 → 설정 → 채팅 → 파일 저장 폴더에서 수동 다운로드한 파일이 남아 있는 경우 직접 삭제가 필요합니다.

03 | 사진·동영상 중복 삭제

같은 사진을 여러 번 찍거나, SNS에서 저장한 사진이 갤러리에 중복으로 쌓이는 경우가 많습니다. 특히 카톡 갤러리 자동저장 설정이 켜져 있으면 대화방 사진이 기기 갤러리에 계속 쌓입니다.
방법안드로이드아이폰
중복 사진 찾기갤러리 앱 내 '정리 제안' 또는 Google Photos의 '중복 항목' 기능사진 앱 → 앨범 → 기타 → 중복 항목
자동 삭제 도구Google Photos '용량 확보' → 클라우드 백업된 원본 삭제iOS '권장 사항' → 자동 최적화
카톡 사진 자동저장 끄기카카오톡 → 설정 → 채팅 → 사진 동영상 자동저장 → OFF동일
💡 동영상을 먼저 정리하세요
동영상 1건은 수백 MB~수 GB에 달합니다. 사진 수백 장보다 동영상 수 편을 지우는 것이 훨씬 효과적입니다. 갤러리에서 용량 큰 순으로 정렬해 필요 없는 동영상을 우선 삭제하세요.

04 | 앱 데이터·캐시 일괄 정리

앱을 오랫동안 쓰면 캐시(임시 저장 파일)가 쌓입니다. 캐시는 삭제해도 앱 자체나 데이터(계정·설정)는 유지됩니다.

안드로이드 앱 캐시 삭제: 설정 → 앱 → 앱 전체 목록 → 용량 큰 앱 선택 → 저장공간 → 캐시 지우기

아이폰 앱 캐시: iOS는 앱별 캐시 직접 삭제가 제한적입니다. 가장 확실한 방법은 앱 삭제 후 재설치입니다. 앱 오프로드 기능(설정 → 일반 → iPhone 저장 공간 → 해당 앱 → 앱 오프로드)을 쓰면 앱 데이터는 남기고 앱만 삭제해 공간을 확보할 수 있습니다.

대용량 캐시 앱 예시: 유튜브(오프라인 저장 영상), 넷플릭스(다운로드 콘텐츠), 네이버 지도(오프라인 지도), 멜론·지니(오프라인 음악)

05 | 구글 포토·아이클라우드로 사진 이전 후 원본 삭제

사진을 클라우드에 백업한 뒤 기기 원본을 지우면 공간을 대폭 확보할 수 있습니다.
플랫폼무료 용량방법
구글 포토구글 계정 15GB 무료(Google One 유료 확장 가능)백업 완료 후 '기기 저장공간 확보' 탭에서 원본 삭제
아이클라우드5GB 무료(유료 업그레이드 권장)사진 → iCloud 사진 ON → 기기 최적화 설정
네이버 MYBOX30GB 무료(네이버 계정 보유자)MYBOX 앱 설치 후 자동 백업 설정
백업이 완료되었는지 반드시 확인한 뒤 원본을 삭제하세요. 삭제 후 30일 이내에는 휴지통에서 복원할 수 있습니다.

06 | 쓰지 않는 앱 삭제

설치해 두고 한 번도 안 쓰거나 거의 쓰지 않는 앱이 상당한 공간을 차지하는 경우가 많습니다.
잘 안 쓰는 앱 찾는 법
안드로이드: 설정 → 디지털 웰빙 → 앱 사용 시간 확인 → 사용 안 한 앱 삭제
아이폰: 설정 → 스크린 타임 → 앱별 사용 시간 확인 → 0분인 앱 정리
게임 앱은 특히 고용량인 경우가 많습니다. 한 게임이 3~5GB를 차지하는 경우도 흔하므로, 더 이상 안 하는 게임은 과감히 삭제하세요.

07 | 안드로이드 SD카드 활용

SD카드를 지원하는 안드로이드 기기라면 SD카드로 사진·파일을 이동해 내부 저장공간을 확보할 수 있습니다. 삼성 갤럭시 일부 모델, LG 구형 모델 등에서 지원하며, 최근 플래그십 모델은 SD카드 슬롯을 제거한 경우가 많습니다.

SD카드 추천 규격: 사진·동영상 저장용은 UHS-I U3 이상(4K 동영상 저장 가능), 용량은 128~256GB가 실용적입니다.

08 | 공간 정리 후 유지 습관 — 월 1회 루틴

주기할 일
매달 1일카카오톡 캐시 삭제
매달 1일구글 포토·아이클라우드 백업 완료 확인 → 원본 정리
분기 1회앱 캐시 일괄 정리, 안 쓰는 앱 삭제
수시카톡 사진 갤러리 자동저장 OFF 유지
정기적으로 정리하면 "저장공간 부족" 알림 없이 쾌적하게 사용할 수 있습니다. 특히 여행이나 가족 행사 전에는 미리 공간을 확보해 두는 습관이 도움이 됩니다.

09 | 그래도 부족하다면 — 클라우드 업그레이드 vs 기기 교체

위 방법을 다 해도 여전히 공간이 부족하다면 두 가지 선택지가 있습니다.

클라우드 저장 업그레이드: 구글 One(100GB 월 2,900원, 2TB 월 11,900원), 아이클라우드(50GB 월 1,100원, 200GB 월 3,300원). 사진 용량이 문제라면 클라우드 확장이 가장 경제적입니다.

기기 교체 고려: 기존 폰이 64GB 이하이고 장기간 사용 중이라면 256GB 이상 새 모델로 교체를 검토할 시점일 수 있습니다. 최신 폰은 기본 128~256GB가 많아 같은 상황이 반복될 가능성이 낮습니다.
