  </div>

## 5. 티스토리 원고 1건 (애드센스 승인용 — `output_tistory/YYMMDD/<slug>.html`)

> ⛔ 티스토리는 **글을 새로 쓰는 일**이다. 네이버 HTML을 CSS만 바꿔 옮기는 것이 아니다. 제목·본문이 네이버와 그대로 같으면 중복 콘텐츠 저품질 위험.

> 🎯 **2026-07-09 재설계 — 티스토리는 사용자 실사진·실경험 기반 '별도' 애드센스 채널**. 미러·날조 AI글이 "가치 없는 콘텐츠"로 반려됨 → 네이버 파생 폐기. **티스토리는 4시 자동 실행에서 생성하지 않는다**(daily-run `$TistorySuspended=$true`로 생성·게이트·스테이징 스킵). 대신 **사용자의 진짜 사진 + 진짜 경험을 소재로 하루 1건, 대화형으로 별도 제작**. 제작 워크플로·표준 = `티스토리_애드센스_제작.md`. 아래 5.2~5.4 원칙은 그 제작에도 그대로 적용(독립 원본·정직·신뢰). ⛔ **이 §5는 자동 실행에서는 실행되지 않는다**(참고용).
>
> **5.1 소재 (네이버와 완전 분리)**: 네이버 자동 원고에서 파생하지 않는다. **사용자가 제공한 실제 사진 + 실제 경험 메모**(다녀온 곳·시기·한 일·관찰·팁·비용)를 소재로, 그 주제의 웹에서 가장 유용한 **진짜 후기/가이드**를 만든다. 진짜 1인칭 경험은 이제 **최고 자산(권장)** — 날조가 아니므로. 정보성 주제면 검증 사실 + 1차 출처로 보강.
>
> **5.2 미러 금지 → 독립 최고 원본**: 네이버 원고를 paraphrase 하지 않는다. 같은 주제로 **처음부터 더 깊고 완결적으로** 쓰고, 네이버판에 없는 **부가가치**를 반드시 넣는다(비교표·단계별 절차·상황별 분기·체크리스트·FAQ·흔한 실수·최신 기준일). 검색자가 다른 데 안 가도 되게.
>
> **5.3 ⛔ 날조 경험 삭제 (핵심 변경)**: "✍️ 직접 가보니" 경험 박스·"평일 오전에 들렀더니" 식 **미체험 1인칭 서술 전면 폐기**. 안 가본 곳·안 해본 절차를 지어내면 구글이 기만적·저품질로 본다. 대신 **정직한 가치**로 신뢰를 만든다 — 검증 사실 + **1차 출처 명시 인용**(정부24·공단·공식 홈) + 최신 기준일 + 솔직한 장단점·한계. "직접 해봤다"가 아니라 "공식 자료를 종합·확인해 정리했다". (실제 개인 경험을 사용자가 보강해 넣는 것은 최고의 자산 — 날조만 금지.)
>
> **5.4 신뢰·UX (정직하게)**: 글 끝 **📝 정보 메모** = 정보 기준일(YYYY-MM-DD) + 인용한 1차 출처 + "요금·일정은 변동되니 공식 채널 재확인". 깔끔한 구조(번호 h2·표·목록)·읽기 쉬운 문단(`<br><br>`)·광고밭 느낌 금지.
>
> 📝 정보 메모 표준 블록:
> ```html
> <div style="background:#eef5f4;border:1px dashed #80cbc4;padding:18px 20px;margin:30px 0;border-radius:8px;font-size:0.95em;color:#444;"><strong>📝 정보 메모</strong><br><br>정보 기준일 YYYY-MM-DD · 출처: [1차 출처명·링크] · 요금·일정은 변동될 수 있으니 공식 채널에서 재확인하세요.</div>
> ```

- **폴더·파일명**: 네이버와 동일 slug.
- **제목** (필수): 네이버 제목과 글자 그대로 같으면 FAIL. 앵글 전환·키워드 재배치·수식어 교체로 단어 일치율 ≤ 60%.
- **본문** (필수): 네이버 원고의 paraphrase가 아니라 **독립 원본**. 동일 팩트(시간·가격·주소·날짜·전화)는 정확히 유지하되, 구성·논지·부가정보(표·FAQ·체크리스트·비교)는 네이버판보다 **확장된 자체 콘텐츠**로. 네이버와 문장 유사도 낮게(게이트 dedup 통과).
- **분량**: 완결성 우선(얇으면 애드센스 반려). 최소 네이버판 이상, **실질 정보로** 채운다(억지 늘리기 금지). h2 9+.
- **출력 형식**: **인라인 `style="..."` 전용**. `<style>` 블록·`class=` 속성·`<script>` 절대 금지(티스토리 에디터가 스트립). 외곽 래퍼 div 강제:
  ```html
  <div style="font-family: 'Apple SD Gothic Neo', sans-serif; font-size: 16px; line-height: 1.9; color: #222; max-width: 780px; margin: 0 auto; padding: 16px;">
  ```
- **표 행 배경**: 각 `<td>`에 직접 `background: #f1faf9;`(여행 짝수행) / `#fff`(홀수행). `nth-child` 안 됨.
- **이미지 (핵심·반복 사고 지점)**: 네이버에서 만든 이미지(`images/YYMMDD/<seq>_<slug>_<idx>.png`)를 **표준 `<img>` 1줄 블록 3개로 재사용한다.** 새 이미지 안 만들고, **네이버의 `img-placeholder` 박스(`📷 AI 이미지 생성 영역`·`📋 프롬프트 복사하기` 등)는 절대 carry over하지 않는다.** 표준 블록:
  ```html
  <div style="margin:30px 0;text-align:center;"><img alt="캡션" src="../../images/YYMMDD/<seq>_<slug>_<idx>.png" style="max-width:100%;height:auto;border-radius:8px;"/><div style="font-size:0.9em;color:#666;margin-top:10px;font-style:italic;">캡션 / AI 제작 이미지</div></div>
  ```
  - `<img>`는 **네이버판과 1:1**(카테고리별 개수 동일 — 여행 `travel_*` 3개, 생활정보 그 외 prefix 2개). 같은 `src` 중복 금지.
  - `alt`·캡션은 네이버와 다른 문구로 재작성(라벨 `/ AI 제작 이미지`는 유지).
  - **⚠️ 캡션은 같은 이미지를 가리켜야 한다 (피사체 고정·문구만 변경)**: 이미지는 네이버와 **완전히 같은 파일**을 공유하므로, 티스토리의 `_<idx>.png` 캡션은 **네이버의 같은 `_<idx>.png` 캡션이 묘사한 피사체·장면을 그대로 유지**한 채 표현(어휘·어순)만 바꿔 쓴다. 예: 네이버 `_2.png`=`청량사 유리보전과 6월 수국` → 티스토리 `_2.png`=`청량사 유리보전 앞 수국`(○). 같은 `_2.png`인데 `강구항 어시장` 같이 **다른 대상**을 적으면 위반(엉뚱한 캡션). 티스토리는 본문 꼭지 순서가 네이버와 달라도 **캡션은 본문 문맥이 아니라 그 이미지가 실제로 보여주는 대상**을 기준으로 쓴다(논리 정합 필수). 작성 후 3개 캡션이 각 src의 실제 피사체와 맞는지 네이버 캡션과 1:1 대조 확인.

- **내부 링크**: 하루 1건이므로 `recommend-area`는 **최근 티스토리 원고 2건**(`../<최근 발행일자>/`의 서로 다른 날, 가능하면 관련 주제)으로 건다. 과거 폴더에 티스토리가 없으면 링크 없이 박스만 두지 말고 가장 근접 2건을 찾는다.
- **해시태그**: 본문 끝에 태그 칩 **10개** (네이버 원본 `.tag` 그대로 또는 동등):
  ```html
  <span style="display:inline-block; background:#f0f0f0; padding:3px 10px; border-radius:5px; margin:3px; font-size:0.85em; color:#666; border:1px solid #ddd;">#키워드</span>
  ```
- **대시보드**: `output_tistory/YYMMDD/index.html` — `<title>`·`<h1>` 글자가 네이버 대시보드와 그대로 같으면 안 된다.

**저장 직전 자가검증** (티스토리 1건):
- [ ] 외곽 래퍼 1개, Platinum h1 1개, 번호 h2 9+, `<style>·class=` 0
- [ ] `<img>` 3개·같은 src 중복 0·placeholder 박스 0, 추천 박스 1개, 태그 칩 10개
- [ ] **미러 아님**: 네이버판에 없는 부가가치 ≥2(표·FAQ·체크리스트·비교 중) 포함, 문장 독립 작성·네이버와 저유사
- [ ] **날조 경험 0**: '직접 가보니·가봤·먹어보니·들렀더니' 등 미체험 1인칭 경험 서술 전무
- [ ] 1차 출처 ≥2 명시 인용 + 정보 기준일 + 공식 재확인 고지(📝 정보 메모)

> 게이트(`.scripts/tistory-gate.ps1`)가 push 직전 자동 검수한다. FAIL이면 wrapper가 commit/push를 차단한다. 위 자가검증을 통과시키면 게이트도 자동 통과.
