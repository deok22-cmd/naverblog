## 5. 티스토리 원고 1건 (애드센스 승인용 — `output_tistory/YYMMDD/<slug>.html`)

> ⛔ 티스토리는 **글을 새로 쓰는 일**이다. 네이버 HTML을 CSS만 바꿔 옮기는 것이 아니다. 제목·본문이 네이버와 그대로 같으면 중복 콘텐츠 저품질 위험.

> 🎯 **2026-07-09 재설계 — 티스토리는 사용자 실사진·실경험 기반 '별도' 애드센스 채널**. 미러·날조 AI글이 "가치 없는 콘텐츠"로 반려됨 → 네이버 파생 폐기. **티스토리는 4시 자동 실행에서 생성하지 않는다**(daily-run `$TistorySuspended=$true`로 생성·게이트·스테이징 스킵). 대신 **사용자의 진짜 사진 + 진짜 경험을 소재로 하루 1건, 대화형으로 별도 제작**. 제작 워크플로·표준 = `티스토리_애드센스_제작.md`. 아래 5.2~5.4 원칙은 그 제작에도 그대로 적용(독립 원본·정직·신뢰). ⛔ **이 §5는 자동 실행에서는 실행되지 않는다**(참고용).
>
> **5.1 소재 (네이버와 완전 분리)**: 네이버 자동 원고에서 파생하지 않는다. **사용자가 제공한 실제 사진 + 실제 경험 메모**(다녀온 곳·시기·한 일·관찰·팁·비용)를 소재로, 그 주제의 웹에서 가장 유용한 **진짜 후기/가이드**를 만든다. 진짜 1인칭 경험은 이제 **최고 자산(권장)** — 날조가 아니므로. 정보성 주제면 검증 사실 + 1차 출처로 보강.
>
> **5.2 미러 금지 → 독립 최고 원본**: 네이버 원고를 paraphrase 하지 않는다. 같은 주제로 **처음부터 더 깊고 완결적으로** 쓰고, 네이버판에 없는 **부가가치**를 반드시 넣는다(비교표·단계별 절차·상황별 분기·체크리스트·FAQ·흔한 실수·최신 기준일). 검색자가 다른 데 안 가도 되게.
>
> **5.3 ⛔ 날조 경험 삭제 (핵심 변경)**: "✍️ 직접 가보니" 경험 박스·"평일 오전에 들렀더니" 식 **미체험 1인칭 서술 전면 폐기**. 안 가본 곳·안 해본 절차를 지어내면 구글이 기만적·저품질로 본다. 대신 **정직한 가치**로 신뢰를 만든다 — 검증 사실 + **1차 출처 명시 인용**(정부24·공단·공식 홈) + 최신 기준일 + 솔직한 장단점·한계. "직접 해봤다"가 아니라 "공식 자료를 종합·확인해 정리했다". (실제 개인 경험을 사용자가 보강해 넣는 것은 최고의 자산 — 날조만 금지.)
>
> **5.4 신뢰·UX (정직하게)**: 글 끝 **📝 정보 메모** = 정보 기준일(YYYY-MM-DD) + 인용한 1차 출처 + "요금·일정은 변동되니 공식 채널 재확인". 깔끔한 구조(번호 h2·표·목록)·읽기 쉬운 문단(`<br><br>`)·광고밭 느낌 금지.
>
> 📝 정보 메모 표준 블록:
